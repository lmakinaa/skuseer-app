# SKUSeer — Frontend

React single-page app for **SKUSeer**, demand intelligence for retail.

## Tech stack

- Vite + React + TypeScript
- Tailwind CSS + shadcn/ui
- Keycloak (OIDC) authentication

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

In production the app is built and served via Docker (see `Dockerfile` and the repo's `docker-compose.yml`).
